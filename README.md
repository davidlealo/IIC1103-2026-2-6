## Evaluación

La nota final se calcula:

```
NF = 15%·I1 + 20%·I2 + 30%·E + 5%·T1 + 5%·T2 + 5%·T3 + 16%·NP + 4%·TIA
```

Donde:

- `I1`, `I2`: Interrogaciones
- `E`: Examen
- `T1`, `T2`, `T3`: Tareas
- `NP`: Nota de participación (definida por cada sección)
- `TIA`: Talleres de Inteligencia Artificial

## Condiciones para aprobar

Se deben cumplir ambas condiciones:

1. Promedio ponderado de interrogaciones y examen ≥ 4.0:
   `(15·I1 + 20·I2 + 30·E) / 65 ≥ 4.0`
2. Nota final ≥ 4.0

Si alguna no se cumple, la nota final es el mínimo entre NF y 3.9.

## Políticas del curso

### Integridad académica

- En interrogaciones y examen: prohibida cualquier ayuda externa (humana o de IA).
- En tareas: prohibida ayuda externa humana. Se permite el uso de herramientas de IA como apoyo para el aprendizaje (aclarar conceptos, revisar errores, sugerir mejoras sobre código propio), pero no para resolver la tarea.

Cualquier falta se reporta a la Unidad Académica del curso.

### Días extra para tareas

Cada estudiante cuenta con 5 días extra en total, distribuibles libremente entre las 3 tareas. No aplican a interrogaciones ni a la nota de participación.

### Inasistencias

Solo se puede justificar la inasistencia a una interrogación (se reemplaza por la nota del examen). Plazo: 10 días desde la inasistencia. Enviar la carta a `iic1103@uc.cl`.

No se puede justificar inasistencia a tareas.

### Reglas técnicas de evaluaciones

- Se considera el último código **ejecutado**, no el último guardado.
- Las evaluaciones presenciales usan Safe Exam Browser (instalar y probar antes).
- Es responsabilidad del estudiante registrar su asistencia. Si no se registra: nota 1.0.
